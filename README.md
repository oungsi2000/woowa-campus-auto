# 우테코 자동등교 기능 명세

### 메인 액티비티 
- [ ] 현재 연결된 와이파이 정보를 보여준다
- [ ] 자동등교 시작 버튼을 누를 수 있다

### 자동등교 시작 버튼을 누르면 다음과 같은 동작을 수행한다

- [ ] 우아한테크코스 캠퍼스 앱이 실행된다
- [ ] 다음과 같은 조건일 때 등교 버튼을 클릭한다
    1. 등교버튼이 아직 눌리지 않았을 때
    2. 캠퍼스 와이파이에 연결되었을 때
- [ ] 다음과 같은 조건일 때 하교 버튼을 클릭한다
    1. 현재 시각이 18:00:10일 때 (약 10초의 지연)
    2. 캠퍼스 와이파이에 연결이 된 상태일 때
- [ ] 클릭에 실패하였을 때, 실패한 이유를 보여준다
